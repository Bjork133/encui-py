# encui-py

Кроссплатформенный TUI-инструмент для шифрования и расшифровки данных на базе **Python** и **Textual**.  
Проект объединяет интерактивную оболочку [encui](https://github.com/Bjork133/encui) и криптографическое ядро [conway-aes](https://github.com/Bjork133/conway-aes) в едином автономном приложении без внешних бинарных зависимостей (`crypto-cli`, `xxd` и т. д.).

---

## Возможности

* **Полная совместимость с `conway-aes` (Rust):** побайтовая идентичность при шифровании и расшифровке.
* **Набор криптоалгоритмов:**
  * `Conway-AES` (трехкомпонентная схема: `public`, `private`, `method`)
  * `AES-256-GCM` (AEAD с генератором случайных 32-байтного `Key` и 12-байтного `Nonce`)
  * `ChaCha20-Poly1305` (AEAD с проверкой целостности)
  * `Vernam / OTP` (одноразовый блокнот, длина ключа `>=` длины данных)
  * `Vigenere` (шифр Виженера по латинскому алфавиту)
  * `Caesar` (классический шифр Цезаря с произвольным сдвигом)
* **Кроссплатформенная работа с файлами:** загрузка произвольных бинарных или текстовых файлов с диска и сохранение результата в форматах `.bin`, `.hex` или `.txt` (UTF-8) на **Windows, Linux и macOS**.
* **Адаптивный TUI-интерфейс:** двухпанельная компоновка с независимой прокруткой, вкладками ввода/вывода и копированием в буфер обмена.

## Как работает Conway-AES

Алгоритм в `crypto_core.py` полностью повторяет оригинальную спецификацию:

1. **Поколения (`derive_generations`):** из первой половины байтов ключа `method` (в порядке big-endian) формируется целое число, которое последовательно делится на `3`, пока не окажется в диапазоне `1..99`.
2. **Побайтовый XOR (`xor_with_method`):** входные данные побайтово накладываются с циклическим повторением ключа `method`.
3. **Клеточная сетка (`apply_n_generations`):** данные укладываются в квадратную матрицу размером $\lceil\sqrt{L}\rceil \times \lceil\sqrt{L}\rceil$, после чего выполняется $N$ обратимых проходов по парам соседних ячеек (`grid[i] ^= grid[i + 1]`).
4. **Формирование ключей (KDF):** из `public` и `private` через `SHA-256` с доменными префиксами `conway-aes/key/v1` и `conway-aes/nonce/v1` вычисляются 32-байтный ключ и 16-байтный IV.
5. **Потоковое шифрование (`AES-256-CTR`):** итоговый массив шифруется стандартным `AES-256` в режиме счётчика (`CTR`).

При расшифровке (`decrypt`) шаги выполняются в строго обратном порядке.

## Установка и запуск

Требуется **Python 3.10+**.

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd encui-py
```

### 2. Установка зависимостей
Рекомендуется использовать виртуальное окружение:

```bash
python -m venv .venv
# Linux / macOS:
source .venv/bin/activate
# Windows:
.venv\Scripts\activate

pip install -e .
```

*(Если доступ к официальному PyPI ограничен, можно указать зеркало Яндекса: `pip install -i https://mirror.yandex.ru/pypi/web/simple -e .`)*

### 3. Запуск интерфейса
После установки пакета запускайте утилиту командой:
```bash
encui
```
Или напрямую как Python-модуль из корня репозитория:
```bash
python -m encui_py.app
```

## Горячие клавиши

| Комбинация | Действие |
| :--- | :--- |
| `Ctrl + R` | Выполнить шифрование или расшифровку |
| `Ctrl + S` | Сохранить полученный результат на диск |
| `Ctrl + L` | Загрузить входной файл по указанному пути |
| `F1` | Открыть встроенное окно справки |
| `Esc` / `Q` | Закрыть модальное окно справки |
| `Tab` / `Shift + Tab` | Переключение между полями (с автопрокруткой панелей) |
| `Ctrl + Q` | Выход из приложения |
